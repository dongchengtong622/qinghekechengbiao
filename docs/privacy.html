一、处理的信息、目的与方式

本应用无需注册或登录，没有广告、用户画像或开发者统计服务器。课程等业务数据由你的设备处理，不自动上传给开发者。你主动导入、填写的信息可能包含教师等他人的信息，请仅导入你有权使用的内容。

  • 课表、学期和作息：课程名称、教师、教室、备注、周次、节次、时间、学期名称、开学日期等，用于展示、编辑课程和安排提醒，存入本机应用私有数据库。
  • Excel 导入：读取你经系统文件选择器选定的 .xls/.xlsx 文件，在本机解析并显示预览。确认导入后写入本地课表。不会扫描全部文件，也不会上传选定文件。
  • 课程提醒：处理提醒开关、时间、通知和闹钟授权状态、铃声、振动、稍后提醒等配置，用于本机提醒。提醒内容可能显示在锁屏、通知中心或桌面组件，能接触设备的人可能看见课程、教师和教室等信息，请按需要设置系统锁屏通知。
  • 本地铃声：读取你主动选择的音频文件，并复制到应用私有区域供提醒使用。系统通知可能通过受限内容 URI 读取该铃声。不会读取你未选择的音频文件。
  • 桌面组件：将当前课表的课程、时间、教师或教室等必要信息生成本地组件快照，交给系统桌面展示，不发送至开发者服务器。
  • 备份与恢复：在你选择的位置导出 JSON 备份，或读取你选择的备份并恢复。你选择第三方云盘或其他文件提供者时，文件由该提供者按其规则保存，本应用不会另行主动上传。导出的文件可能包含课程和设置，请妥善保管。
  • 诊断与反馈：提醒故障检查会在本机读取手机厂商、型号、Android 版本、系统构建信息、权限状态及有限提醒诊断记录，用于说明兼容性和提醒状态，不自动上传。反馈输入在页面中编辑，点击复制后写入系统剪贴板，由你自行发送。你主动发来的邮件、截图或文字，由开发者为答复问题处理；不需要身份证、账号密码等无关信息。
  • 隐私选择：在应用的不可备份私有区域保存已同意的政策版本及独立联网选择，用于记住选择。更新政策版本时，重新提示同意。
  • 节假日在线更新：默认关闭。主动单独同意开启后，仅在课程提醒和法定节假日静默均开启、需要加载年度数据时，请求第三方节假日服务。涉及信息见第三条。

本应用不为业务功能读取 IMEI、通讯录、地理位置、相册，不申请摄像头或麦克风权限。不会用课表建立广告画像。

二、系统权限及用途

权限分为系统自动授予的普通权限、运行时权限及需要系统设置授权的特殊访问权限；并非所有权限都会出现授权弹窗。你可通过系统设置控制相关权限，拒绝后可能无法使用对应提醒功能，不影响本地查看或编辑课表。

  • INTERNET（网络访问）：仅在独立联网选择开启、课程提醒开启且法定节假日静默开启时获取年度节假日数据。权限在安装时由系统授予，应用用内部开关限制请求。
  • POST_NOTIFICATIONS（发送通知）：Android 13 及以上发送课程提醒，使用提醒功能时请求。
  • VIBRATE（振动）：在你选择振动提醒时振动。
  • RECEIVE_BOOT_COMPLETED（开机广播）：已同意政策后，在重启设备时恢复已设置的提醒及组件刷新。
  • SCHEDULE_EXACT_ALARM（精确闹钟）：在系统允许且你授权时精确安排课程提醒。
  • FOREGROUND_SERVICE（前台服务）：响铃期间维持有可见通知的提醒服务。
  • FOREGROUND_SERVICE_MEDIA_PLAYBACK（媒体播放前台服务）：提醒响铃时播放铃声。
  • WAKE_LOCK（唤醒锁）：提醒服务短时运行时保持设备唤醒。
  • USE_FULL_SCREEN_INTENT（全屏提醒）：在系统允许且你授权时显示锁屏课程提醒。

Android 组件还声明本应用专属的 DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION 签名权限，用于限制动态广播接收的来源。这不是访问你的通讯录、位置、文件等个人信息的权限，不需要你额外授权。

Excel、备份和铃声使用系统文件选择器，不申请读取全部外部存储、照片库或音频库权限。

三、第三方节假日服务

服务名称：免费节假日 API（提莫的神秘小站）；域名：timor.tech；服务说明：https://timor.tech/api/holiday。服务由该网站独立运营，不是开发者的数据服务器。公开接口说明未明确运营主体实名、服务器所在地、访问日志保存期限或专门隐私政策。

发送的信息：URL 中的年份和固定参数 week=Y；连接过程中第三方可能获得 IP 地址、访问时间、请求路径、客户端协议信息等网络日志。不发送课表、教师、教室、铃声、备份或反馈内容。

用途是获取法定节假日及调休数据；不需账号、密钥或学校登录。数据从你的设备直接请求该服务。开发者无法替该服务控制、查询或删除已产生的服务器日志，也不承诺日志仅保存在境内。

默认不联网，你可在“设置 → 关于与帮助 → 隐私与联网设置”查看说明后单独选择“同意并开启”。随时关闭“节假日在线更新”可终止当前请求并停止后续请求；关闭“法定节假日静默”或“上课提醒”后，不再为该用途发起新的请求。关闭功能不使已经发生的第三方日志自动删除。

关闭联网仍可使用内置 2026 年及已缓存的节假日数据。缓存和未来年份可能不完整，第三方服务不承诺稳定性；学校校历与国家法定节假日可能不同，请自行核对。开源组件见应用内“第三方组件与联网服务”和“开源许可”，本地组件的使用不等于向组件作者上传数据。

四、存储、安全和期限

课程数据库、配置、提醒日志、缓存、组件快照及导入铃声保存在本机应用私有区域。应用关闭 Android 自动备份，同意标记另放在不可备份区域；系统或设备厂商的换机机制可能有差异。你主动导出的备份位于你选择的位置。

课表和设置保留至你删除内容或通过系统清除应用数据；卸载一般会清除应用私有数据，但不会替你删除外部备份、原始 Excel、原始音频和已发送的反馈。提醒诊断记录按本机有限条数保留。节假日缓存可在系统清除应用数据时删除。开发者收到的反馈以解决问题所需期限保留，一般在问题处理完毕后六个月内删除或匿名化；依法需要保留或存在未解决争议时按必要期限处理。

本应用使用系统沙箱和授权文件访问，不提供开发者远程访问课表的入口。本地课表和 JSON 备份并未额外加密；系统权限、设备锁屏和你对导出文件的保管仍很重要。请定期导出备份，设备丢失、清除数据或卸载后，开发者无法从服务器替你找回课表。

本应用不使用 Cookie，不内嵌网页追踪。查看法律文档不联网。

五、你的权利和操作路径

  • 查阅、复制与导出：在课表页面查看信息，在“设置 → 数据管理 → 备份与恢复”导出 JSON。
  • 更正：编辑课程，或在“课表与学期”“作息时间”修改相应内容。
  • 删除：可删除课程；删除全部本地信息前建议备份，再到 Android 系统设置 → 应用 → 青禾课表 → 存储，清除应用数据。导出文件需在保存位置另行删除。
  • 撤回联网同意：关闭“隐私与联网设置 → 节假日在线更新”。
  • 撤回整体隐私同意：在“隐私与联网设置”选择“撤回隐私同意并退出”。将关闭联网、取消提醒并清空桌面组件的课表快照。课表数据库保留供你以后重新同意使用；需要删除时按上述路径清除数据。再次启动将重新显示同意页面。
  • 撤回系统授权：在系统设置中关闭相应权限。无需注销账号，因为本应用没有账号。
  • 对已主动发送给开发者的反馈，可通过邮箱提出查阅、更正、删除等请求。仅在确有必要时核实与你请求有关的信息，不要求提供无关证明。

撤回同意不影响撤回前基于有效同意开展处理的效力。对无法直接控制的第三方服务日志，你可向该服务提出请求或联系开发者寻求协助。

六、未成年人

本应用主要面向大学生。未成年人应由监护人指导阅读并使用。不满十四周岁用户不得开启第三方联网功能或向开发者发送个人信息；如需处理该年龄段的个人信息，应另行取得监护人的有效同意并制定专门规则。本版本未提供该专门流程。监护人可联系开发者提出删除已收到信息等请求。
