# 青禾课表导入提醒和周次选择改进设计

日期：2026-09-21  
目标版本：0.4.0+4  
实现分支：codex/course-import-reminders

## 目标

在现有草稿 PR #1 的课程导入和 Android 提醒功能上完成稳定性修复，并增加课表首页周次选择。最终交付可直接安装测试的 Android Release APK，同时生成 AAB 供后续发布使用。

## 当前状态

相关功能尚未合并到 main，完整代码位于 codex/course-import-reminders 分支。现有首页只显示由当前日期计算出的周次，用户不能主动查看其他周。Excel 导入只解析第一个非空 Sheet，列名和数据格式兼容范围有限。提醒规划混用了设备本地 DateTime 与 Asia/Shanghai 调度时间，权限状态展示也未区分通知权限和精确闹钟权限。

## 周次选择

TimetablePage 改为维护当前查看周次的有状态页面。

- 周次入口显示在学期名称后方，点击后列出第 1 周至学期 totalWeeks 的全部周次。
- 当前实际周在列表中标记为“本周”。
- 正在查看当前周时，标题显示“第 N 周 · 本周”。
- 正在查看其他周时，标题旁显示“回到本周”快捷按钮。
- 选择周次只改变页面显示内容，不改变系统实际周次、课程数据或提醒排程。
- 学期切换时重置为新学期当前周；当前日期不在学期范围时默认显示第 1 周且不显示“本周”入口。
- 当前周使用上海时区计算。

## 上海时区统一

新增集中式上海时区工具，负责初始化 timezone 数据、返回上海当前时间并创建上海时区日期时间。

- ReminderPlanner 使用 timezone.TZDateTime 计算课程开始时间和提醒时间。
- QingheApp 传入 ReminderPlanner 的 now 使用上海时区。
- FlutterLocalNotificationGateway 直接调度已经带 Asia/Shanghai 时区的 TZDateTime，避免再次按设备本地字段重建时间。
- 首页本周计算也使用上海日期。
- 测试覆盖设备位于非上海时区时的提醒时间不偏移。

## Excel 导入

ExcelTimetableImporter 遍历全部 Sheet，并优先选择同时具有课程名称和星期语义表头的工作表。说明页、封面页和空 Sheet 会被跳过。

建立规范字段与别名映射，至少支持：

- 课程名称：课程、课程名、课程名称
- 星期：星期、周几、上课星期
- 节次：开始节次和结束节次，以及“节数”“上课节次”中的第 1-2 节写法
- 周次：开始周和结束周，以及“上课周次”“周数”中的 1-18周、1,3,5周、单周、双周写法
- 时间：开始时间、结束时间、上课时间
- 教师和教室常见别名

无法解析的单行加入 ImportPreview.warnings 并继续处理；缺少学期、第一周日期或无法识别任何有效课程时仍返回明确错误。

将用户此前使用的真实青禾课表模板保存为 test/fixtures 下的 xlsx 回归样本。parseBytes 集成测试覆盖真实日期单元格、时间单元格、空行、多 Sheet、单双周和重复课程。

## 通知 ID 和铃声

通知 ID 的稳定键包含课程 ID、星期、开始节次、结束节次、教室、开始周、结束周、单双周模式和实际周次。测试覆盖同一课程同一天同一开始节次但结束节次或教室不同的情况。

继续为每种铃声使用独立 Android 通知 Channel ID，避免 Android 8 及以上版本因 Channel 不可变导致切换铃声不生效。更换铃声后重新排程全部未来提醒。自动化测试验证铃声映射和 Channel ID；真机最终效果由交付 APK 验收。

## 权限和调度状态

权限模型分开表达通知权限与精确闹钟权限。

提醒设置页分别显示：

- 通知权限状态
- 精确闹钟权限状态
- 当前实际调度模式：精确或可能延迟
- 对应的系统设置入口

通知权限拒绝时不能启用提醒。通知权限允许但精确闹钟权限拒绝时允许启用，并明确提示使用非精确调度。返回应用时刷新权限状态并重新排程。
