# 青禾课表基础版本设计

## 目标

建立可持续扩展的 Flutter 双平台项目基础。本阶段交付可离线运行的课程数据模型、单双周判断、示例周课表页面，以及 Android 可构建验证。iOS 工程同时生成，但因当前只有 Windows 开发条件，本阶段不承诺 iOS 签名构建。

## 范围

- Flutter Android/iOS 共享代码工程。
- 学期、课程、上课时段三个核心实体。
- 指定周、单周、双周课程判断。
- 首个周课表页面，展示周一至周日、节次、课程名、教室和教师。
- 成都文理学院作为首批教务适配对象，仅预留导入边界；本阶段不采集教务账号，也不实现网页抓取。

不在本阶段实现登录、云同步、通知、考试作业或真实教务导入。这些功能将在基础模型稳定后分阶段加入。

## 架构

客户端采用按功能分层的轻量结构：

- `core/theme`：全局视觉样式。
- `features/timetable/domain`：不依赖 Flutter UI 的课程领域模型。
- `features/timetable/presentation`：课表页面和组件。
- `features/timetable/data`：当前使用内存示例数据，后续替换为 Drift 本地库。

课程 `Course` 与上课安排 `CourseSession` 分离。同一门课可对应多个时间、教室和周次规则。`Semester` 负责把日期映射到教学周。

## 数据规则

`CourseSession` 包含星期、起止节次、起止周和周次模式。课程是否在某周发生必须同时满足：处于起止周范围内，并符合每周、单周或双周模式。输入不合法时通过构造断言和显式校验失败，避免生成无法排课的数据。

## 页面设计

首页使用清爽的青绿色视觉：顶部显示学期与当前周；日期栏可查看一周；主体按每天分组展示课程卡片。手机端采用纵向列表，保证第一版可读性和无障碍触达；后续再增加横向网格和周次切换动画。

## 错误处理

- 无课程时展示明确空状态。
- 不合法节次或周次在领域层拒绝。
- 当前日期不在学期内时，周次返回空值，不伪造教学周。
- 后续导入数据先转换为领域模型并校验，只有完整有效的数据才写入本地库。

## 测试与验收

- 单元测试覆盖每周、单周、双周、边界周和学期周次计算。
- Widget 测试验证页面标题、课程及教室信息可见。
- `flutter analyze` 无错误。
- `flutter test` 全部通过。
