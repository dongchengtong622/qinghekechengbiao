# Android 本地课程管理设计

## 目标

把青禾课表从只读示例升级为可安装、可离线使用的 Android 课程表：课程数据保存在 SQLite，用户可新增、编辑和删除课程，应用重启后数据仍然存在。

## 范围

- 仅验证和交付 Android APK。
- 使用 Drift 2.35.0、drift_flutter 0.3.1 和 SQLite。
- 保存课程名称、教师、颜色，以及星期、节次、教室、起止周和每周/单周/双周规则。
- 首次打开且数据库为空时写入三门演示课程；用户删除后不重复恢复。
- 首页订阅数据库变化并自动刷新。
- 支持新增、编辑和删除；删除必须二次确认。

本阶段不实现账号、云同步、通知、作业考试和教务系统导入。

## 架构

`AppDatabase` 定义课程表和上课安排表，`CourseRepository` 是 UI 唯一依赖的数据接口。数据库行由映射器转换为现有的 `Course` / `CourseSession` 领域模型，页面不直接依赖 Drift 类型。应用入口创建数据库并注入首页，页面销毁时不提前关闭全局数据库。

## 数据模型

课程表以字符串 ID 为主键，保存名称、教师和颜色。上课安排表以自增 ID 为主键，通过 `courseId` 外键关联课程；删除课程时事务内先删除安排再删除课程。新增或编辑课程要求至少一条上课安排，本阶段表单一次编辑一条安排。

## 交互

首页右下角提供“添加课程”按钮。点击课程卡片进入编辑表单；长按或卡片菜单可删除。表单校验课程名称、星期、节次顺序、周次范围和教室。保存成功后关闭表单，数据库流触发首页刷新；失败时保留输入并显示提示。

## 测试与交付

- 使用内存 SQLite 测试新增、更新、删除、监听与首次种子数据。
- Widget 测试覆盖新增入口、表单校验、编辑和删除确认。
- CI 执行代码生成、格式检查、静态分析、全部测试和 Android debug APK 构建。
- 最终交付 CI 生成的 `app-debug.apk`。
