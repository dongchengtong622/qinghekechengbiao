# 青禾课表：提醒可靠性与本地铃声设计

日期：2026-09-22
状态：功能范围已获用户确认；本规格待审阅。
基线：PR #1，9f970baa27f1449e3cccae1a18899c911ac55834。
目标版本：0.5.0+5。保持草稿 PR，不合并 main，不发布应用商店。

## 目标和边界

兼容 Android 7.0（API 24）及以上；重点验收 iQOO 8 / Android 14。
修复课前无提醒与笼统状态报错，新增预设铃声、本地音频导入、试听和测试提醒。
系统强行停止、关闭通知、勿扰或厂商后台限制可能阻止声音，不承诺绕过系统设置。
不删除用户课表，不要求以卸载作为修复步骤。

## 已知证据与未决原因

设置页面将权限读取与重新调度包在同一 catch 中，因此调度失败也会显示“无法读取提醒状态”。
调度器先 cancelAll 再逐项设置；中途失败可能导致提醒丢失或仅部分成功。
这两点是代码中确认的问题，不等于已经确认该手机无声的具体根因。
实现前需检查 Release APK 中动态引用的音频/图标是否被资源压缩移除、原生调度异常、待处理提醒、学期日期与时间计算。
保留异常阶段和错误码；不得仅修改提示文案就宣称修复。

## 选定方案与取舍

扩展现有 Flutter 提醒规划器和 Android 通知调度层，增加独立的铃声管理与试听适配层。
相比仅引导系统设置，该方案能区分权限、任务注册和声音失败；相比重写闹钟服务，改动范围更小。
通知声音使用系统通知机制，试听使用播放器；不使用持续后台播放来伪装通知。

## 提醒流程

1. 分离设置读取、权限检测、任务规划、系统注册、注册核对五个阶段。
2. 读取已注册提醒，依据稳定 ID 更新目标任务；不要在新任务注册前清空所有旧任务。
3. 新任务注册完成后清理过期任务；显式关闭提醒时取消课程提醒，不误删独立测试提醒。
4. 部分失败如实报告成功数与失败原因，不显示“全部成功”；提供重试。
5. 显示最近一次同步结果、已注册任务数量、下一次课程提醒时间（上海时区）。
6. 注册结果只能证明系统接受任务，不能证明手机实际弹出或发声。
7. 无通知权限时给出入口；无精确闹钟权限时标明非精确模式及可能延迟。
8. 返回前台刷新权限并协调一次调度，避免应用和页面重复发起互相覆盖的调度。

## 铃声与本地音乐

保留系统默认与现有三种铃声，新增四种短铃声，共八个预设选项。
每个选项提供试听/停止；只允许一个试听播放，离开页面停止。
“添加本地音乐”调用系统文件选择器，支持设备可解码的 MP3、WAV、M4A、OGG；限制 20 MB。
取消选择不改现有设置；不可解码或超限时明确提示。
复制音频到应用持久目录，保留原文件不修改；通过 Android 可读取的持久 content URI 供通知使用，并验证跨进程访问。
不得把仅当前进程可读的文件路径直接当作后台通知铃声地址。
铃声身份与通知频道绑定，更换音频时使用不同频道标识，避免频道声音不可变导致仍播旧声音。
旧设置迁移到对应预设；自定义文件失效时提示并回退系统默认，不静默失去提醒。
本轮不提供音频剪辑、整首循环播放或云音乐下载。

## 测试与界面

新增“立即测试通知”和“1 分钟后测试”，两者都走真实原生通知路径。
测试任务使用独立 ID，不因返回前台同步课程提醒被取消。
显示测试计划时间，提示锁屏等待；试听成功与通知测试成功分开显示。
错误信息使用中文阶段说明与可复制的技术详情，不包含课表内容等无关个人信息。
提供 iQOO 后台运行、通知渠道声音和电量限制的检查指引，不冒充自动改变系统设置。

## 验收和交付

自动测试覆盖权限拒绝、部分注册失败、旧任务保留、重复前台事件、时间边界、铃声迁移与文件失效。
Release 包检查最低 API 24、版本 0.5.0+5、通知资源和原生接收器是否实际存在。
条件允许时测试 API 24/26/31/33/34 与构建时可用的较新 API；未运行的设备版本列为未验证。
iQOO 真机必须分别验证：立即通知、1 分钟锁屏通知、真实课程提前 30 分钟、预设声音、本地音乐、重启后提醒。
无真机连接时不能声称上述测试已通过，交付测试 APK 并附操作步骤。
提供通用 APK、arm64 APK 和 AAB；发布签名与旧安装签名是否一致需核对，不能建议用户未经备份卸载。
